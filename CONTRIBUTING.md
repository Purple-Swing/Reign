# Contributing

You can contribute to Reign by opening issues or pull requests about topics that need improvement or development.

---

### Notice
- Keep issues or pull requests concise and clear so that they are more understandable.
- Do not create unnecessary issues or pull requests.

---

### Issues

Mainly, issues can be used to request new features or bug reports on certain parts of Reign. Issues allow people to suggest things so that we can continue expanding Reign with new features.

> [!TIP]
> If your issue is left open for an extended period of time, do not close it. It is probable that we are developing other things and could take some time to get around to it.

---

### Pull Requests

Pull requests are more versatile than issues, they can attempt to fix more than one problem and can be submitted by anybody with a GitHub account.

> [!IMPORTANT]
> Pull requests are manually reviewed by Tureen for safety and security, larger pull requests may take a longer amount of time to review.
