# Changelog | v1.0.3.4

- Audio System now sets previously missing fields with entry data
- Save System's `RefreshHandlers()` function is now public
- Mixer System no longer contains a default mixer group
- `ReignMonoBehaviour` now contains a cached Transform component
- `BoxTrigger` class now uses `event Action` instead of `UnityEvent`
- `TimeMeasurementObject` was renamed to `TimedReignMonoBehaviour`
- `VideoListener`s now throw a `TaskCanceledException` if `AwaitStopPlaying()` is called whilst the video player is looping
