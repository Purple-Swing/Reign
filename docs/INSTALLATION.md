# Installing Reign

0. Setup
   - Download [Unity 6000.4.4f1](https://unity.com/releases/editor/whats-new/6000.4.4f1) and the [Unity Hub](https://docs.unity.com/en-us/hub/install-hub).
   - Download the [newest release](https://github.com/Purple-Swing/Reign/releases/latest) of Reign
   - Create a new folder for your Unity project that will use Reign. Unzip the downloaded Reign archive here.
   - Once Reign has fully extracted into the project folder, it should look like this:
   <br><img src="/docs/images/projectExample.png" width="500">
   <br>

1. Open
   - Next, open <b>Unity Hub</b> and select `Add > Add project from disk` and then locate and select the project folder you created.
   - If you have <b>Unity 6000.4.4f1</b> installed the project should open automatically. If you do not: download it when prompted.
   <br>

2. Personalise
   - Reign has been successfully installed. 
   - Check the [wiki](https://github.com/Purple-Swing/Reign/wiki) to find out how to customise/personalise your project using <b>Config</b>.
