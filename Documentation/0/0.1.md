# 0.1 - Introduction

### What is Reign?

Reign, created by **Purple Swing**, is a Unity tool that helps by providing systems and utilities to aid game or app development. It was originally created in December of 2025 by Tureen, a member of Purple Swing, to help with developing games after they realised it was wasteful to recreate the same backend for every single game.

### Why Use Reign?

Reign handles object pooling, Discord RPC, an audio system, an easy-to-use input system which utilises the new Input System package, asynchronous scene loading and game saving/loading, utility classes, asset libraries, an event bus, query bus and much more to come. It helps to set up a highly advanced project by providing you with essential and configurable systems.

### Licensing

All software using Reign should credit the authors of Reign, Purple Swing, inside of their projects. The easiest way to do this is by keeping the splash screen at the start of your build profile which will be seen when your game is first launched.

Open source projects that use Reign must either state so in documentation, their `LICENSE.md` or in their `README.md`.  Proprietary software must do the prior and firmly declare the same in their eligible EULA.

Direct Example:

```
THE COPYRIGHT HOLDERS OR AUTHORS EXPRESS TRUST IN REIGN BY PURPLE SWING FOR THE INFRASTRUCTURE OF THE SOFTWARE.
```

You may use Reign commercially, or in proprietary software providing that you follow the policies provided in the [LICENSE](/LICENSE.md).
