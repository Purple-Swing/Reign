# 2.5 - The Discord System

The Discord System connects Reign to Discord with controllable Discord Rich Presence data.

---

### Attempting Connections

From the first frame, the `DiscordSystem` tries to see if it `CanConnect`, if it cannot `Disconnect()` will run: which disposes of `Discord`. Otherwise, if `Discord` is null, a new instance of `Discord` and calls `UpdateStatus()`.

On Update, `CanConnect` is set to the opposite of `IsConnected` before `AttemptCallbacks()` is called.

---

### Attempting Callbacks

If `Discord` is null, the function is returned. Otherwise it tries to call `RunCallbacks()`, if for whatever reason it cannot, `Disconnect()` will run.

---

### Update Status

If `Discord` is null, the function is returned. Otherwise, it tries to set the current manager is set by null-coalescing by using `Discord.GetActivityManager()`.

The current activity of the manager is updated with the `currentDiscordSystemSettings` by setting every variable to its corresponding one.

Then `IsConnected` is set to if the update of the activity was sucessful.

---

### DiscordSystemData

The struct `DiscordSystemData` contains corresponding variables to the Discord `Activity` struct. Using `SetData(DiscordSystemData data)`, if the current data isn't equal to the parametic data, the `currentDiscordSystemSettings` updates along with the status.

---

##### Footnotes

- `DiscordSystemData` does not contain Party or Secret fields yet, and is planned for a later version of Reign.
