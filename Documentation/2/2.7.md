# 2.7 - The Display System

The Display System controls everything to do with resolution, fullscreen, post process and V-Sync.

---
### How It Works

The Display System accesses the post processing bool as well as the screen resolution, fullscreen and V-Sync settings which are within `GameData`.

Using `IDataHandler`, when the `LoadData(data)` function is called, the `globalVolume` is enabled if the `data.screenResolution.postProcess` bool is true. The `QualitySettngs.vSyncCount` is set to 1 or 0 dependent of `data.screenResolution.vsync`. Then `Screen.SetResolution(data.screenResolution.width, data.screenResolution.height, data.screenResolution.fullscreen)` is called, which sets the width, height and fullscreen value of the application's screen.

When saved, the `data.screenResolution` values are set to the current `Screen.width`, `Screen.height`, `Screen.fullScreen`, `QualitySettings.vSyncCount` and the current `data.screenResolution`'s `postProcess` value.
