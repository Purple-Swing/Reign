# 2.6 - The Scene Load System

The Scene Load System is fundamental to Reign because it allows for asynchronous scene loading, along with fading transitions between them.

---

### How It Works

To swap the active scene from `LoadScene(name, transitionSpeed)`, Reign's Scene Load System must first call `TransitionAsync(isIn, speed)`. The `isIn` parameter determines whether the black overlay should fade in or out, and the speed determines how fast the alpha of the overlay should move to the target value of 1 or 0 depending if `isIn` is true. The speed of the transition is set by `LoadScene` from the passed in parameter.

Then, after the Scene Load System has awaited the overlay transitioning to pure black the active scene, which is given by the name parameter, is changed.

After the active scene is changed, the Scene Load System does the opposite of the first step, and sets the alpha of the overlay back to 0 using `await TransitionAsync(false, transitionSpeed)`.

Here is the full function:

```
public async Task LoadScene(string name, float transitionSpeed = 1.0f)
{
    // Fade in
    await TransitionAsync(true, transitionSpeed);

    // Await load
    await LoadSceneAsync(name);

    // Fade out
    await TransitionAsync(false, transitionSpeed);
}
```

<br>

To call the function you must either use it in an async function or use a discard:

- ##### Await Async Method
    `await SceneLoadSystem.Instance.LoadScene("My Scene Name", 1.0f);`

- ##### Discard Method
    `_ = Reign.Systems.SceneLoadSystem.Instance.LoadScene("My Scene Name", 1.0f)`

---

### Load Scene Async

The private `LoadSceneAsync(name)` task uses a `TaskCompletionSource` of type `bool` and assigns it to true once the Unity Scene Manager completes `LoadSceneAsync` with your scene name parameter.

```
private Task<bool> LoadSceneAsync(string name)
{
    var completionSource = new TaskCompletionSource<bool>();

    SceneManager.LoadSceneAsync(name).completed += _ =>
    {
        completionSource.SetResult(true);
    };

    return completionSource.Task;
}
```
